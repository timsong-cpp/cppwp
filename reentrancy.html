16.4.6.9 Reentrancy [reentrancy]

1
#
Except where explicitly specified in this document, it is implementation-defined which functions in the C++ standard library may be recursively reentered.
2
#
During the execution of a standard library non-static member function F on an object, if that object is accessed through a glvalue that is not obtained, directly or indirectly, from the object parameter of F, in a manner that can conflict ([intro.races]) with any access that F is permitted to perform ([res.on.data.races]), the behavior is undefined unless otherwise specified.
